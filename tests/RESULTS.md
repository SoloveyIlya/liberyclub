# Проверка PHP-миграции

Проверено локально 14.10.2026 на PHP 8.5.11.

- 39 проверок PHP: валидация, уникальные сеансы, события видео/кнопки/анкеты, все 6 шагов, средний максимальный таймкод, UTC+3 и границы дней, пустые периоды, UTM и старые записи, заявки, ответы, хранение и rate limit.
- Полное совпадение всех полей PHP-отчёта с прежней Node-версией на одинаковом наборе данных.
- 28 HTTP-запросов: защита аналитики, верный/неверный пароль, cookies, logout, некорректные даты и запросы, запись событий, UTM-агрегация, пустой период и недоступность приватных файлов.
- Успешная отправка через реальный PHP endpoint с заменой только исходящего HTTP-транспорта тестовыми ответами: Google + 2 чата Telegram, сохранение UTM и заявки. Ошибка доставки возвращает 502 и не создаёт ложную конверсию.
- Браузер: вход, отчёт, заявки, диапазон 7 дней; VSL с UTM → запуск видео → таймкод → кнопка → анкета; появление данных в PHP-аналитике.
- Проверен fallback ID сеанса для HTTP-страниц без crypto.randomUUID.
- Живой Telegram getMe: успешная авторизация без отправки сообщений.
- Google Forms GET: HTTP 429 со стороны Google; живая отправка не выполнялась. Это ограничение проверки, а не подтверждение доставки.

Для повторения:

```sh
php tests/check.php
# Сервер с отдельным хранилищем тестовых событий:
LIBERTY_STORAGE=/tmp/liberty-qa php -S 127.0.0.1:3110 tests/router.php
# В другом терминале (Python нужен только для тестирования):
python3 tests/http-check.py
python3 tests/lead-http-check.py
```

Проверки не проводились на хостинге пользователя. Там нужно включить PHP 8.1+, cURL, сессии, доступ PHP на запись в storage и исходящий HTTPS.

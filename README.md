# Liberty Club

VSL-страница, пошаговая анкета и защищённая аналитика с UTM-атрибуцией.

## Запуск

Нужен Node.js 20 или новее. Дополнительные пакеты не требуются.

1. Скопируйте `.env.example` в `.env` и задайте токен Telegram-бота и пароль аналитики.
2. Перенесите видео отдельно в `assets/VSL_oct.mp4`. Большие видеофайлы не хранятся в Git.
3. Запустите `npm start`.
4. Откройте `http://localhost:3000`, аналитика — `/analytics`.

Адрес Google Forms и получатели Telegram настроены в `server.js`. Для отправки анкеты необходим работающий Node.js-сервер, статического хостинга недостаточно.

События и заявки сохраняются в `data/events.jsonl`; папка `data` и файл `.env` исключены из репозитория. На сервере используйте постоянное хранилище для `data` и настройте резервное копирование.

## Проверки

```sh
node --test analytics-report.test.js utm.test.js
```

# Liberty Club — PHP-хостинг

Node.js, npm, база данных и отдельный постоянно работающий сервер не нужны.

## Установка

1. В панели хостинга выберите **PHP 8.1 или новее** с расширением **cURL** и поддержкой PHP-сессий.
2. Загрузите файлы сайта в папку домена, включая `.htaccess` (он может быть скрыт).
3. Скопируйте `config.example.php` в `config.php`. Укажите `telegram_token` и `analytics_password`. Готовый локальный `config.php` уже содержит текущие настройки, но не хранится в Git.
4. Загрузите видео отдельно: `assets/VSL_oct.mp4`.
5. PHP должен иметь право создавать и записывать папку `storage` рядом с `api.php`. Если автоматическое создание недоступно, создайте папку через панель хостинга и разрешите запись пользователю PHP. Не задавайте права 777.
6. Откройте главную страницу и `/analytics.html`. Работает также установка в подпапке. `/analytics` поддерживается при включённом Apache mod_rewrite.

Сайт вызывает `api.php` напрямую; перезапись URL для анкеты и аналитики не нужна. Видео отдаёт сам хостинг. Исходящие HTTPS-запросы к `docs.google.com` и `api.telegram.org` должны быть разрешены.

Настройки Google Forms и получателей Telegram находятся в `php/defaults.php`; при необходимости переопределите ключи в `config.php`.

## Аналитика и данные

События хранятся в `storage/events.php`. Начало файла блокирует чтение данных через HTTP даже без правил Apache. Не удаляйте PHP-заголовок и не переименовывайте файл в `.txt` или `.jsonl`. Делайте резервные копии папки `storage`. Не заменяйте её при обновлении сайта.

Считаются уникальные сеансы, старты видео, клики по кнопке, шаги анкеты, заявки и средний максимальный таймкод. Даты — Минск (UTC+3). Фильтр дат применяется ко всем разделам. UTM сохраняются в событиях, заявке и сообщении Telegram; в Google Forms передаются отдельным блоком ответа «Что изменится».

Историю старой Node-версии можно один раз импортировать на компьютере с PHP:

```sh
php tests/import-events.php /path/to/events.jsonl
```

После этого перенесите `storage/events.php` на хостинг. Не загружайте старую папку `data`, `.env`, `.git` или тесты в публичную папку сайта. Секреты хранятся только в `config.php`, который при HTTP-запросе не выводит их.

## Локальная проверка (только для разработки)

```sh
php tests/check.php
php -S 127.0.0.1:3107 tests/router.php
```

На хостинге ничего из этого запускать не надо — PHP обрабатывается веб-сервером автоматически.
